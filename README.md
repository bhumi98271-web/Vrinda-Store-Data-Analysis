# Vrinda Store Data Analysis — 2022

## 📌 Project Overview

This project analyzes Vrinda Store's 2022 sales data using Microsoft Excel. The goal is to understand sales performance, customer purchasing behavior, order status, and sales channel performance through data analysis and an interactive dashboard.

## 🎯 Project Objectives

* Analyze monthly sales and order trends.
* Compare sales between men and women.
* Identify top-performing states.
* Analyze order status, including delivered, returned, cancelled, and refunded orders.
* Compare orders across different sales channels.
* Understand customer demographics by age group and gender.

## 🛠️ Tools Used

* Microsoft Excel
* Data Cleaning
* Pivot Tables
* Data Analysis
* Charts and Data Visualization
* Interactive Dashboard

## 📂 Dataset Information

The dataset contains **31,048 order-level records** with information such as:

* Order ID and Customer ID
* Gender and Age Group
* Order Date and Month
* Order Status
* Sales Channel
* Product Category, SKU, Size, and Quantity
* Sales Amount
* Shipping Information

## 📊 Key Insights

* **Gender Analysis:** Women generated approximately ₹1.36 crore in sales, compared with approximately ₹76.14 lakh for men.
* **Monthly Sales:** March recorded the highest monthly sales, while November recorded the lowest among the months analyzed.
* **Top State:** Maharashtra recorded the highest sales, followed by Karnataka.
* **Order Status:** Most orders were delivered, while a smaller number were returned, cancelled, or refunded.
* **Sales Channels:** Amazon recorded the highest number of orders, followed by Myntra and Flipkart.
